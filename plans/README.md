# The plans

[00-design.md](00-design.md) is transom's design: why it exists, its
principles, and its architecture. Each numbered plan covers one part of
the system: the problem, the design, and the reason for each decision.

A plan starts as a stub that records the decisions made so far and the
questions still open, and it fills in as the design of that part is
settled. The Markdown files in this directory are the plans that are not
built yet. A plan closes in the commit that builds it, which moves it to
`completed/` and dates its header.

A new plan takes the next number after the highest one in this
directory and its subdirectories. A number never changes.
