transom

transom lets an agent or a program ask a person a question and get the answer back.

The question arrives on the person's phone as a notification they can answer in place, and also waits in their inbox, on the web and in the app. transom is a small server you run yourself, with an HTTP API, an MCP server, a web inbox, and an Android app.

A deploy script asks, and waits up to ten minutes for the answer:

$ curl -s -H "Authorization: Bearer $token" -H 'Prefer: wait=600' \
    -H 'Summary: Deploy web 2026.11.07 to production?' \
    -H 'Choices: "Deploy", "Not yet"' \
    -d 'All checks passed on staging.' \
    https://transom.example.com/@chris | jq '{state, reply}'
{
  "state": "replied",
  "reply": {
    "at": "2026-11-07T22:15:45.337Z",
    "by": "@chris",
    "by_name": "Chris",
    "by_picture": null,
    "choice": "Deploy"
  }
}

The repository has the server, the app, and the whole API as examples.
