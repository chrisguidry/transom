transom

transom lets an agent or a script ask a person a question and get the answer back. It is a small server you run yourself, with an HTTP API, an MCP server, a web inbox, and an Android app.

An agent asks with the ask tool, and waits up to ten minutes:

ask {
  "to": "@chris",
  "summary": "Merge the retry fix into main?",
  "body": "CI passed. The change adds a backoff to webhook retries.",
  "choices": ["Merge", "Hold"],
  "wait": 600
}

The question arrives on Chris's phone:

He taps Merge, and ask returns the exchange with "state": "replied" and "choice": "Merge" in its reply. A script sends the same question with one curl request.

The repository has the server, the app, the agent skills, and the whole API as examples.
