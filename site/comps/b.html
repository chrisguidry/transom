transom

Ask a person a question from an agent or a script, and get the answer back.

A deploy script asks Chris, and waits up to ten minutes:

$ curl -s -H "Authorization: Bearer $token" \
    -H 'Prefer: wait=600' \
    -H 'Summary: Deploy web 2026.11.07 to production?' \
    -H 'Choices: "Deploy", "Not yet"' \
    -d 'All checks passed on staging.' \
    https://transom.example.com/@chris \
    | jq '{state, reply}'

He taps Deploy, and the request returns with his answer:

{
  "state": "replied",
  "reply": {
    "at": "2026-11-07T22:15:45.337Z",
    "by": "@chris",
    "by_name": "Chris",
    "by_picture": null,
    "choice": "Deploy"
  }
}

transom is a small server you run yourself, with an HTTP API, an MCP server for agents, a web inbox, and an Android app. A question waits in the inbox until someone answers it or it expires.

The repository has the server, the app, and the whole API as examples.
